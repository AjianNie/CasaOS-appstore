# Ajian CasaOS AppStore

基于 CasaOS AppStore V2 格式的个人应用商店，仅通过 GitHub Release 发布最新版。

## 旧版 CasaOS

```text
https://github.com/AjianNie/CasaOS-appstore/releases/download/new/AppStore.zip
```

## CasaOS AppStore V2

```text
https://github.com/AjianNie/CasaOS-appstore/releases/download/new/dist.zip
```

每次推送应用配置或元数据后，GitHub Actions 会重新构建并覆盖 `new` Release，同时发布旧版 `AppStore.zip` 和 V2 版 `dist.zip`。
